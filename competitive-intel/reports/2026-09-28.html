📊 Intelligence by Product Category

🛡️ Endpoint Protection (1 new item)

🆕 Microsoft Defender Adds Local AI Agent Discovery to Identify and Inventory Agentic AI on Endpoints (September 24, 2026)
🏷 Microsoft Defender  |  📅 September 24, 2026
As part of its September 2026 security roundup, Microsoft added Local AI Agent Discovery to Defender, giving security teams a way to identify and inventory AI agents running on employee devices so agentic activity can be discovered and controlled rather than operating invisibly. The same update adds Security Copilot–generated explanations of URL and file sandboxing results to speed SOC investigation, and extends Intune's Enterprise Application Management, Cloud PKI, and Remote Help to GCC High and DoD environments. COMPETITIVE IMPLICATION: Microsoft is treating autonomous AI agents as a new managed-asset class inside its existing endpoint security console rather than shipping a bolt-on tool, which sets a baseline expectation that endpoint protection platforms should natively discover agentic AI the same way they discover unmanaged software. PORTFOLIO ANGLE: Worth checking whether our EP/EDR telemetry can currently distinguish an autonomous AI agent process from ordinary application activity on a managed endpoint — this is an emerging visibility gap several vendors are now racing to close.

🔍 Endpoint Detection & Response (1 new item)

🆕 SentinelOne Extends Wayfinder Threat Hunting to AWS, Azure, and Google Cloud (September 25, 2026)
🏷 SentinelOne  |  📅 September 25, 2026
SentinelOne expanded Wayfinder threat hunting to cover AWS, Azure, and Google Cloud, combining AI-powered telemetry from the Singularity Platform with expert-led hunting to monitor cloud control planes alongside endpoints and identities. Coverage includes detection of IAM privilege escalation, unauthorized access, data exfiltration, S3 reconnaissance, and suspicious policy changes, all mapped to MITRE ATT&CK with AI-summarized findings for triage; existing Wayfinder customers gain the new coverage through marketplace plugins. This builds on Wayfinder's earlier AWS/LevelBlue expansion (reported August 10) with a distinct capability: full cloud-control-plane hunting rather than a channel partnership. COMPETITIVE IMPLICATION: SentinelOne is positioning itself as a unified XDR player spanning endpoint, identity, and cloud rather than a pure-play EDR vendor, directly pressuring competitors whose cloud visibility is thinner or requires a separate product. PORTFOLIO ANGLE: Worth a comparison of our own EDR's cloud workload and IAM-misconfiguration visibility against Wayfinder's new scope, especially for MSP clients whose customers run meaningful workloads in public cloud.

🎓 Security Awareness Training / HRM (1 new item)

🆕 KnowBe4 Expands Agent Risk Manager With a Browser Extension for Real-Time Shadow-AI Governance (September 23, 2026)
🏷 KnowBe4  |  📅 September 23, 2026
KnowBe4 added a native Chrome/Edge browser extension to its Agent Risk Manager product (originally launched mid-2026) that lets security teams allow, warn, or block employee access to known AI sites the moment it happens — not just detect unauthorized use after data exposure — with quantified usage metrics and one-click governance requiring no external tools or engineering tickets. KnowBe4 cites survey data that 52% of organizations report their AI use is unapproved or ungoverned, and the extension integrates with existing phishing simulation, awareness training, and risk-scoring data for a unified behavioral risk profile. It's currently in early access for Security Awareness Training Advanced customers, with broader rollout planned in coming months. COMPETITIVE IMPLICATION: This is a shift from awareness-only content toward active, real-time enforcement — a capability standalone shadow-AI monitoring tools and traditional SAT libraries alike don't combine today. PORTFOLIO ANGLE: Worth evaluating whether our SAT/HRM offering needs an active governance layer (allow/warn/block) for shadow AI, rather than only training content about AI risk, since KnowBe4 is now selling enforcement, not just education.

📌 Strategic Context: AI Agents Are Becoming a Managed-Asset Category in Their Own Right

All three items this week point at the same underlying shift: AI agents — both sanctioned enterprise agents and unsanctioned "shadow AI" tools employees adopt on their own — are being treated as a distinct category that security platforms must discover, inventory, and govern, not just a feature bolted onto existing products. Microsoft is doing this at the endpoint-inventory layer, SentinelOne is doing it by widening its detection surface into the cloud control plane where agentic workloads increasingly run, and KnowBe4 is doing it at the point of human interaction with browser-based AI tools. None of these are detection-quality plays in the traditional sense — they're all about extending visibility and control to a category of activity that didn't exist as a defined asset class eighteen months ago. PORTFOLIO IMPLICATION: Worth a short cross-functional review of whether Endpoint Protection, EDR, and SAT/HRM each have a concrete answer to "can we see and govern AI agent activity" — three competitors moved on this in the same week, which suggests it's becoming a baseline buyer expectation rather than a differentiator.
