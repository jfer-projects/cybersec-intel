🔴 Microsoft June 2026 Patch Tuesday: All-Time Record 198–206 CVEs

🆕 CVE-2026-45586 (GreenPlasma): Windows CTFMON Elevation of Privilege — Actively Exploited Zero-Day (June 9, 2026)

Microsoft's June 9, 2026 Patch Tuesday set an all-time record with 198–206 CVEs addressed in a single release, surpassing the previous record of 167 CVEs (October 2025). The headline zero-day: CVE-2026-45586, dubbed "GreenPlasma" by researcher Nightmare Eclipse, exploits an improper link resolution vulnerability in the Windows Collaborative Translation Framework (CTFMON). Successful exploitation gives an attacker a SYSTEM shell via local privilege escalation. Actively exploited before the patch was available. Patch: included in June 9 cumulative update. Affected: Windows 10, Windows 11, Windows Server 2016–2026.

Other Notable CVEs in June 2026 Patch Tuesday:
  • CVE-2026-50507 — Windows BitLocker Security Feature Bypass (Important): Physical/local access enables circumventing full-disk encryption. Patched.
  • CVE-2026-44801, CVE-2026-44799, CVE-2026-42992, CVE-2026-42985 — Remote Desktop Client RCE cluster (Critical): 11 total RDP CVEs addressed this cycle; 4 rated Critical. Risks remote code execution from a malicious RDP server.
  • CVE-2026-41091 — Microsoft Defender for Endpoint Elevation of Privilege (Important): Patched in this cycle.
  • Scope: 33 Critical-rated CVEs total; 28 are RCE; 4 EoP; 1 information disclosure.
Portfolio Impact:
  • 🔴 Endpoint/EDR: GreenPlasma actively exploited — CTFMON EoP detection required immediately; SYSTEM-level compromise indicators
  • 🔴 MDR: 33 Critical CVEs, 28 RCE — prioritize RDP exposure monitoring; BitLocker bypass detection on physical-access threat vectors
  • 🔴 Endpoint Protection: Defender for Endpoint CVE-2026-41091 EoP patched — ensure update deployment complete for all managed endpoints
  • 🟠 Threat Intel: Record patch volume = expanded attack surface for unpatched orgs; prioritize Windows CTFMON, RDP, BitLocker in threat modeling

⚠️ Trend Signal: Patch Volume as Attack Surface Indicator

The all-time record 198–206 CVEs in a single Microsoft Patch Tuesday signals accelerating vulnerability discovery — driven by AI-assisted code auditing and increased security researcher activity. CRITICAL IMPLICATION: Orgs that can't patch at Patch Tuesday velocity are increasingly exposed between cycles. The gap between zero-day disclosure and weaponization is narrowing. GreenPlasma was already being exploited before the patch dropped. MDR providers must assume active exploitation of high-severity CVEs before customers can patch. Recommendation: Treat unpatched critical Windows endpoints as actively compromised in threat modeling until update verification is confirmed.

🔴 ShinyHunters Oracle PeopleSoft Zero-Day: CVE-2026-35273 — 100+ Orgs Breached

🆕 CVE-2026-35273: Oracle PeopleSoft Environment Management RCE — ShinyHunters Extortion Campaign (June 10–11, 2026)

ShinyHunters exploited CVE-2026-35273, a critical remote code execution flaw in Oracle PeopleSoft's Environment Management component, via a "gadget chain" combining known vulnerabilities with previously undisclosed flaws. Google Threat Intelligence and Mandiant confirmed malicious activity between May 27 and June 9, notifying 100+ global organizations. Over 300 PeopleSoft instances were compromised. Oracle issued an emergency out-of-band patch on June 11 — four days after silently applying a server-side fix. Education sector bore the brunt: universities and higher education institutions were primary victims. One confirmed victim had 40 GB of data — covering ~500,000 current and former students — published on ShinyHunters' extortion site.

Attack Profile:
  • Vulnerability: CVE-2026-35273 (Critical RCE, CVSS 10.0 per CISA KEV listing)
  • Exploitation window: May 27 – June 9, 2026 (13 days before public disclosure)
  • Scope: 300+ PeopleSoft instances; 100+ organizations worldwide
  • Data impact: 40 GB confirmed stolen (education sector); extortion demands reported
  • Patch: Oracle out-of-band patch June 11, 2026 (previously silently applied server-side June 5)
  • CISA action: CVE-2026-35273 added to Known Exploited Vulnerabilities (KEV) catalog
Portfolio Impact:
  • 🔴 MDR: Critical: Oracle PeopleSoft now active attack vector; detect PeopleSoft lateral movement to endpoint environment; data exfiltration monitoring
  • 🔴 Threat Intel (BrightCloud): ShinyHunters IP ranges and C2 infrastructure classification priority; extortion campaign IOC enrichment
  • 🟠 EDR: Post-PeopleSoft compromise: endpoint lateral movement from compromised PeopleSoft server; LSASS dump and credential harvesting patterns
  • 🟠 SAT: Education sector phishing risk elevated (500K student data in ShinyHunters hands); spear-phishing secondary wave likely

🟠 Shai-Hulud Mini: Red Hat npm Supply Chain Worm Resurges

🆕 32 @redhat-cloud-services npm Packages Backdoored with Self-Propagating Credential-Stealing Worm (June 2, 2026)

On June 2, 2026, 32 packages published under the @redhat-cloud-services npm namespace were compromised and republished with a new variant of the Shai-Hulud supply chain worm. The malicious payload — a new variant of TeamPCP's Mini Shai-Hulud (open-sourced May 2026) — extracts developer credentials, API keys, and cloud configurations, encrypts them with AES-256-GCM, and uploads them to public GitHub repositories accessible only to the threat actor's private key. The worm uses npm's bypass_2fa publish parameter to republish itself even from accounts with 2FA enabled, making it self-propagating. Affected packages serve 80,000–117,000 average weekly downloads.

Attack Chain:
  • Targeted namespace: @redhat-cloud-services (32 packages, 96 malicious versions)
  • Propagation: npm bypass_2fa parameter bypasses two-factor authentication on publish
  • Payload: Extracts keys, credentials, cloud configs → encrypts AES-256-GCM → uploads encrypted to public GitHub
  • Scope: 80K–117K avg weekly downloads at risk; developer CI/CD pipelines targeted
  • Attribution: Linked to TeamPCP's Mini Shai-Hulud malware (open-sourced May 12, 2026)
  • Also targeting: Bitwarden CLI package (@bitwarden/cli) for key extraction
Portfolio Impact:
  • 🟠 Endpoint/EDR: Developer workstations primary infection vector; detect npm postinstall script execution with network exfiltration activity
  • 🟠 MDR: Cloud credential exfiltration to GitHub; monitor for unusual cloud API usage following npm install events
  • 🟠 Threat Intel: Open-source worm tooling democratizes supply chain attacks; expect more campaigns using TeamPCP toolset
  • 🟠 SAT: Developer-targeted social engineering likely as follow-on to credential theft; targeted phishing with harvested org context
