Critical development: CISA added Arista VeloCloud Orchestrator CVE-2026-114625 (CVSS 9.9, exploited, third VCO flaw since July) and Collabora Online/Nextcloud CVE-2026-110447 (CVSS 9.2, web-shell activity) to KEV on October 23 with an October 26 federal deadline. 🔴 Actively Exploited: Network Orchestration and Collaboration Platforms

🆕 CVE-2026-114625: Arista VeloCloud Orchestrator SQL injection exploited (CVSS 9.9)
CISA added the flaw to KEV on October 23 with a federal deadline of October 26. Authenticated SQL injection in on-premises VCO (minimum role Enterprise Read Only) can expose privileged internal functionality. Fixed in 5.2.3.18, 6.1.3.10 and 6.4.2.12. Arista says it is known to be exploited, shared two Japan-geolocated IPs (74.82.197[.]86, 38.54.50[.]151) and has not attributed it. The Hacker News counts this as the third VCO flaw exploited since July (after CVE-2026-16812 and CVE-2026-93952, both CVSS 10.0).
PORTFOLIO IMPACT: SD-WAN orchestrators sit in many MSP-managed SMB networks. Patch on-prem VCO, restrict management access, and hunt for the listed IPs; EDR/MDR customers should confirm network-device telemetry coverage.

🆕 CVE-2026-110447: Collabora Online built-in CODE server (Nextcloud richdocumentscode) command injection exploited (CVSS 9.2)
OS command injection via proxy.php when the CODE local document server is not running; fixed in September in version 26.4.303. Attackers have planted web shells on Nextcloud servers and search for credential stores, password-manager artifacts and crypto wallets.
PORTFOLIO IMPACT: Self-hosted Nextcloud is common among small businesses and MSP-hosted file shares. Web-shell activity should trigger EDR/MDR detections on web-server processes; confirm patch status and look for unexpected proxy.php requests.

🆕 Mid-October KEV additions: BeyondTrust Remote Support, Ivanti Connect Secure, Palo Alto PAN-OS, Fortinet, Atlassian, Ahsay, Cisco ESA
Per a secondary weekly summary, nine entries were added October 13–16, including BeyondTrust Remote Support CVE-2026-102764 (auth bypass), Ivanti Connect Secure CVE-2026-104935 (auth bypass), PAN-OS CVE-2026-0322 (code injection), two Ahsay AhsayCBS flaws (CVE-2026-105133/105134, backup server), Cisco Secure Email Gateway CVE-2026-76519 (path traversal), Atlassian CVE-2026-21589 and Fortinet CVE-2025-61624. Ransomware use is listed as unknown for all. Windows CVE-2026-96951 was already covered October 19. CVSS scores and details were not verified against NVD/CISA.
PORTFOLIO IMPACT: Remote-support and backup tools (BeyondTrust, AhsayCBS) are direct MSP tooling; treat as priority checks. Edge VPN and email-gateway flaws reinforce the case for EDR plus MDR coverage and for DNS filtering of post-exploitation callbacks.

📌 Strategic Context

Exploitation continues to concentrate on infrastructure that sits outside endpoint agents: SD-WAN orchestrators, VPN gateways, remote-support and backup servers. For MSP/SMB customers this argues for pairing EDR with MDR monitoring of server and network-device logs, and for fast patch workflows on MSP's own tooling. Coverage this week relied on a news outlet plus a secondary KEV roundup; verify against CISA before acting.
