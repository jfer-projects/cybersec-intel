🔴 Gentlemen RaaS / GentleKiller: BYOVD EDR Killer Targeting 400+ Processes Across 48 Vendors

🆕 ESET Research: GentleKiller Framework — Modular EDR Killer Suite Embedded in Gentlemen RaaS (June 18–21, 2026)

ESET Research published a detailed analysis of the Gentlemen ransomware-as-a-service (RaaS) operation and its GentleKiller EDR killer framework — a suite of at least 8 BYOVD (Bring Your Own Vulnerable Driver) variants designed to terminate endpoint detection and response processes before ransomware payload deployment. The framework targets 400+ security processes across 48 endpoint security vendors, including CrowdStrike Falcon, SentinelOne Singularity, Microsoft Defender for Endpoint, ESET Endpoint Security, and Kaspersky. GentleKiller abuses legitimate but vulnerable signed drivers — including those from Kaspersky (eb.sys), FACEIT Anti-Cheat (nseckrnl.sys), Valorant (GameDriverX64.sys), Javelin/Safetica (stpm_old.sys/stpm_new.sys), Zemana WatchDog (dmx.sys), Qihoo 360 (360netmon_wfp.sys), and IObit (IMFForceDelete) — to elevate privileges and kill security engine processes. Additionally, the Gentlemen operator incorporates third-party or leaked tools (HexKiller, ThrottleBlood, HavocKiller) alongside GentleKiller variants.

Key Technical Characteristics:
  • BYOVD technique: Imports legitimate signed drivers with known vulnerabilities → exploits kernel-level access to kill EDR processes from ring-0
  • 8 GentleKiller variants: Each impersonates a different legitimate security product to avoid detection-by-name heuristics
  • Rapid PoC weaponization: Gentlemen incorporated UnknownKiller and PoisonKiller tools within days of their public GitHub PoC disclosure — demonstrating an operationally agile offensive R&D pipeline
  • Centralized RaaS model: Unlike most RaaS operators who leave EDR killing to affiliates, Gentlemen provides GentleKiller as a standardized, ready-to-use suite — lowering affiliate skill floor and accelerating attack consistency
  • Scope: 400+ security processes; 48 named vendors including CrowdStrike, SentinelOne, Microsoft, ESET, Kaspersky, Sophos
Portfolio Impact:
  • 🔴 Endpoint/EDR (Critical): EDR agents on Windows endpoints are now explicit, named targets. BYOVD attacks operate at kernel level — standard process-protection is insufficient. Require tamper-protection that survives driver-level attacks and kernel-level agent protection. Validate agent tamper-protection capabilities against BYOVD scenarios.
  • 🔴 MDR (Critical): If endpoint agents are killed pre-encryption, MDR behavioral detection must operate independently of the local agent — network-level telemetry, cloud-side SIEM correlation, and identity-based anomaly detection become the last line of defense. Validate MDR detection coverage for the "agent-killed" scenario.
  • 🟠 Threat Intel (BrightCloud): Gentlemen RaaS IOCs: C2 infrastructure, GentleKiller driver hashes, and post-compromise data exfiltration destinations require classification and reputation enrichment.
  • 🟡 SAT/HRM: Ransomware deployment typically follows a phishing/credential compromise initial access step — SAT training remains the first-line prevention layer before GentleKiller reaches the endpoint.

⚠️ Trend Signal: EDR Killing as a RaaS Feature

Gentlemen's decision to centralize and standardize EDR killing represents an industrialization of a capability that was previously a differentiator for only the most sophisticated threat actors. By embedding GentleKiller into the RaaS platform and providing it to all affiliates, Gentlemen lowers the skill floor for ransomware operators significantly. The rapid PoC-to-production cadence (days, not weeks) indicates dedicated offensive R&D — a development pipeline with engineering resources comparable to enterprise security companies. The security industry implication is clear: relying on endpoint agent presence as a detection assumption is no longer viable. Detection and response must operate across multiple redundant telemetry sources — endpoint agent, network, identity, cloud — so that agent termination does not create a blind spot.

🔴 FortiBleed: 86,644 Fortinet Device Credentials Compromised — CISA Emergency Alert June 18

🆕 FortiBleed Campaign: Russian-Speaking Threat Actors Extract Credentials from 86K+ Fortinet FortiGate Devices (CISA Alert June 18, 2026)

On June 18, 2026, CISA issued an emergency advisory after the FortiBleed campaign surfaced: threat actors have systematically extracted configuration files from approximately 74,000–86,644 internet-facing Fortinet FortiGate firewalls and SSL VPN gateways. The actors cracked the stored administrative credential hashes from these configs, resulting in verified working administrator credentials for a massive pool of network perimeter devices. The campaign spans 194 countries, affecting both government and private-sector organizations. Security researchers attribute the operation to Russian-speaking threat actors leveraging weak passwords, reused credentials, and outdated Fortinet firmware. The credentials were then compiled and distributed in threat actor communities. Arctic Wolf published independent analysis confirming active exploitation across all 194 countries as of June 19.

Attack Profile and Scope:
  • Devices affected: 74,000–86,644 Fortinet FortiGate firewalls and SSL VPN gateways
  • Method: Configuration file extraction from internet-accessible management interfaces → credential hash cracking
  • Scope: 194 countries; government + private sector
  • Attribution: Russian-speaking threat actors (financially motivated, possible pre-positioning for ransomware)
  • Risk: Active exploitation — threat actors possess working admin credentials for affected devices
  • CISA action (June 18): Emergency advisory; urges immediate credential reset and session termination
  • Specific note: Affects both FortiGate firewalls AND Fortinet Spark firewalls (SMB-targeted product line)
Portfolio Impact:
  • 🔴 MDR (Immediate): Organizations with Fortinet perimeter devices should treat all admin sessions as potentially compromised pending credential rotation. Threat hunt for lateral movement originating from FortiGate management interfaces; new admin accounts; VPN session anomalies; configuration changes
  • 🔴 DNS Protection: Compromised FortiGate = compromised network perimeter; DNS exfiltration and C2 beaconing through perimeter devices becomes viable. Ensure DNS monitoring covers traffic originating through FortiGate interfaces
  • 🟠 Endpoint/EDR: Perimeter compromise is a common lateral movement precursor; correlate FortiGate anomalies with endpoint behavioral signals across MSP customer environments
  • 🟠 Threat Intel (BrightCloud): Fortinet FortiBleed actor infrastructure should be classified; credential dumps used in downstream attacks need IOC enrichment
  • 🟡 SAT/HRM: Fortinet Spark is an SMB-targeted product — MSP customers with Spark firewalls in client environments need urgent communication

🟠 Klue/Icarus SaaS Supply Chain Breach — OAuth Token Theft Exposes Salesforce Data of Security Vendors

🆕 Icarus Extortion Group Exploits Dormant Klue OAuth Credential to Steal Salesforce Data from Huntress, Recorded Future, Tanium & Others (June 11–22, 2026)

Klue, a competitive intelligence SaaS platform, was compromised by Icarus — a financially motivated extortion group that emerged in April 2026. On June 11, threat actors used a long-dormant OAuth credential (originally created to test an integration that was never deployed) to access Klue's backend infrastructure, push malicious code, and harvest live OAuth tokens for all connected customer SaaS integrations. The harvested tokens were used to access and exfiltrate data from customers' Salesforce environments. Klue confirmed the breach and deactivated all OAuth integrations (Salesforce, HubSpot, SharePoint, Zoom, Gong, Chorus, Clari, Google Drive, Slack) on June 12. Victims include Huntress, Recorded Future, Tanium, Jamf, Sprout Social, Gong, and Insurity. Icarus listed Klue on its extortion leak site on June 21. Huntress independently disclosed the incident and published its own investigation on June 22.

Attack Chain and Key Facts:
  • Initial access: Dormant OAuth credential from an abandoned integration test (Klue's own failure, not a phishing attack)
  • Lateral movement: Backend code injection → harvest live OAuth tokens for all active customer integrations
  • Exfiltration target: Salesforce CRM instances of Klue customers
  • Confirmed victims: Huntress, Recorded Future, Tanium, Jamf, Sprout Social, Gong, Insurity (and likely others)
  • Extortion: Icarus demanded payment; Huntress received "mr bean" alias extortion communication pointing to Icarus Session Messenger ID
  • Response: Klue notified customers June 12; all OAuth tokens deactivated; integrations disabled
  • Pattern: Icarus is a new extortion group (April 2026) demonstrating sophisticated SaaS supply chain attack methodology
Portfolio Impact:
  • 🟠 MDR (High): SaaS-to-SaaS OAuth token chains are now a proven, scalable exfiltration vector. MDR telemetry needs to cover OAuth grant anomalies, unexpected Salesforce API calls from third-party integrations, and high-volume record exports from CRM systems
  • 🟠 SAT/HRM: Dormant credential hygiene is a human risk management issue — abandoned integrations and unused credentials are an underappreciated attack surface. Directly relevant to SAT content around credential lifecycle management and SaaS sprawl
  • 🟡 Threat Intel (BrightCloud): Icarus extortion group infrastructure (C2, leak site URLs, Icarus actor aliases) requires classification and enrichment
  • 🟡 Endpoint/EDR: Post-exfiltration endpoint indicators of compromise; watch for data staging activity on developer workstations at affected organizations

🟡 CISA Known Exploited Vulnerabilities (KEV) — New Additions This Week

🆕 Cisco SD-WAN Manager CVE-2026-20262 — Actively Exploited Zero-Day; LiteSpeed cPanel CVE-2026-54420 (Week of June 16–22)

CISA added two new vulnerabilities to the Known Exploited Vulnerabilities (KEV) catalog during the week of June 16–22: (1) Cisco SD-WAN Manager CVE-2026-20262 — an actively exploited zero-day in Cisco's SD-WAN Manager (vManage) product, confirmed in wild exploitation with an urgent patch deadline; (2) LiteSpeed Technologies cPanel CVE-2026-54420 — a high-severity flaw in the LiteSpeed web server cPanel integration, issued with a 2-day federal remediation deadline. Additionally, multiple prior KEVs including Oracle PeopleSoft CVE-2026-35273 and Ivanti deadline reminders carried overdue status this week, bringing the total overdue KEV count to 7 as of June 19.
